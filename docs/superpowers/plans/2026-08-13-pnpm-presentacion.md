# pnpm y presentacion de LedgerHarbour Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task with review checkpoints.

**Goal:** Convert LedgerHarbour to a pnpm-only local workflow and replace the temporary root page with a presentable public entry point.

**Architecture:** Keep the existing Next.js route structure and development authentication unchanged. The package-manager work is repository-wide configuration/documentation cleanup, while the visual work stays inside the root route and the existing global layout, using server-rendered links and CSS with no new runtime dependency.

**Tech Stack:** Next.js 15, React 19, TypeScript, pnpm 11.21.0, Playwright, Vitest.

## Global Constraints

- Use `pnpm` for install, development, tests, lint, typecheck, build, and E2E commands.
- Keep one lockfile: `pnpm-lock.yaml`; remove `package-lock.json`.
- Use only synthetic local-demo copy and data; do not add credentials or external services.
- Preserve `/login`, `/register`, onboarding, portfolio, invoice, and tenant-isolation behavior.
- Keep the landing responsive, keyboard navigable, and free of emoji icons.
- Do not modify persistence or production authentication as part of this task.
